## Editing the ontology

1. Clone the repository (or fork it if you are not a team member).
2. Create a branch, e.g. `git checkout -b issue123`.
3. Open `src/ontology/aopo-edit.owl` in [Protégé](https://protege.stanford.edu/).
4. Make your edits, commit, push, and open a pull request.
